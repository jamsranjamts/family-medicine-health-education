# Өрхийн эмнэлгийн эрүүл мэндийн боловсролын Quarto site

Энэ package нь олон нийтэд зориулсан эрүүл мэндийн боловсролын цахим сайт хийхэд зориулагдсан.

## Доторх сэдвүүд

1. Тархины цус харвалт
2. Зүрхний шигдээс
3. Эпилепси
4. Бөөрний дутагдал
5. Аутизм, хэл засал, хөдөлгөөн засал, хөдөлмөр засал
6. Тархины харвалтаас үүдэлтэй саажилтын үеийн дасгал хөдөлгөөн
7. Холголт, цооролт
8. QR код ба татах материал

## Ажиллуулах

1. Quarto суулгана: https://quarto.org/docs/get-started/
2. RStudio дээр `one_click_build_and_qr.R` файлыг нээнэ.
3. Run all дарна.
4. `docs/` folder дотор HTML site үүснэ.

## Online байрлуулах үнэгүй хувилбар

- GitHub Pages
- Netlify
- Posit Connect Cloud

## QR код

Сайт online URL-тай болсны дараа `one_click_build_and_qr.R` доторх:

```r
site_url <- "https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/"
```

гэдгийг өөрийн URL-аар солиод дахин ажиллуулна. QR кодууд `qr/` folder дотор үүснэ.

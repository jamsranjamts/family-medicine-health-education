# GitHub Pages дээр үнэгүй байрлуулах товч заавар

## 1. GitHub account үүсгэх

https://github.com дээр account нээнэ.

## 2. Repository үүсгэх

Жишээ нэр:

```text
family-medicine-health-site
```

Public repository болгоно.

## 3. Site folder upload хийх

Энэ folder доторх бүх файлыг repository руу upload хийнэ.

## 4. GitHub Pages асаах

Repository → Settings → Pages → Branch хэсэгт:

```text
Branch: main
Folder: /docs
```

гэж сонгоод Save дарна.

## 5. URL авах

Хэдэн минутын дараа ийм URL гарна:

```text
https://username.github.io/family-medicine-health-site/
```

## 6. QR код үүсгэх

`one_click_build_and_qr.R` доторх `site_url`-г дээрх URL болгоод Run all хийнэ.

QR кодууд:

```text
qr/
```

folder дотор гарна.
